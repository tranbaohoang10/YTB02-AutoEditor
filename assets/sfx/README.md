# Transition SFX

Place short, locally licensed transition sounds here. Supported names begin with
`paper_swipe`, `paper_rustle`, `page_turn`, or `soft_whoosh`; supported formats
are WAV, MP3, and M4A. Missing assets never block rendering: the scheduler keeps
the visual transition and records `scheduled_visual_missing_sfx` in diagnostics.

The bundled WAV files are deterministic procedural sounds generated by
`tools/generate_builtin_sfx.py`; they contain no sampled or copyrighted audio.
